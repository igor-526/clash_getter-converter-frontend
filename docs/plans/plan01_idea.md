# Контекст
Мы сделали backend для генерации YAML нод конфигов для FlClashX из RAW ссылок. Теперь нам нужно под этот backend сделать простой интерфейс
# Тестирование
Backend доступен на `http://localhost:32768/`. Используй OpenAPI JSON и протестируй запросы перед разработкой
# Концепция UX
Интерфейс делится на 2 колонки
**Слева:**
- input для ввода наименования конфигурации
- radio input для ввода формата output JSON или YAML. По умолчанию YAML
- TextField для ввода ссылки конфигурации. Учти, что там может быть полноценный конфиг WireGuard
- Кнопка генерации
**Справа:**
- TextField для вывода. Пользователь может его отредактировать
- Кнопка копирования
### Мобильная версия
Блоки делятся не на левый и правый, а второй блок находится под первым. При нажатии на кнопку генерации пользователя перекидывает на TextField готовой генерации и кнопки для копирования
